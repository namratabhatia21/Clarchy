# 0003: The LLM proposes, code calculates

**Status:** accepted · 2026-10-01

## Context

Language models produce plausible but sometimes wrong prices, and inconsistent diagram
layouts. Trust is the product's main differentiator.

## Decision

- The LLM (phase 4) only turns an idea into requirements and a neutral spec chosen from
  the pattern library. Its output is validated by the same Pydantic models as hand-written
  specs.
- Diagram layout is deterministic code (`render.py`), never generated by the model.
- Prices (phase 2) come only from provider price data, with SKU, unit, region and date
  recorded for every line.
- The model may phrase explanations, but rationales for built-in patterns are written
  and reviewed by people.

## Consequences

- Outputs are reproducible and testable with golden files.
- The model can only design what the pattern library and capability list allow. That
  limits creativity on purpose; the library grows over time.
