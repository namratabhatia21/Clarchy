    From brief to drawing

    1

    Read the brief

    Type it, or drop in a Word, PDF or Excel file. Paragraphs and tables are read alike, and nothing leaves your browser.

    2

    Mark up what matters

    The numbers that size a design are picked out: users, traffic, data, uptime, region, compliance and budget. Anything missing becomes a question for you.

    3

    Draw the architecture

    An agent chooses each service with MCP tools, from the edge to the data, and says why, quoting your own words.

    4

    Add build and deploy

    Source control, CI, a registry, a release pipeline and infrastructure as code come with every design.

    5

    Trace the workflows

    A request, a release, a background job: each one is a numbered path through the drawing.

    6

    Every cloud, with costs

    The same design is drawn for AWS, Azure, Google Cloud and open source, priced from one month to three years.

              Sheet 05 · About

              About Clarchy

              Clarchy turns a requirements brief into a cloud architecture you can question, price and compare across AWS, Azure, Google Cloud and open source.

              Founder

              Namrata Bhatia

              Founder and creator of Clarchy

              Namrata is an AWS educator. She built Clarchy to make architecture decisions explainable: every service tied to the requirement that asked for it, priced from real list prices, and drawn the same way on every cloud.

              Contactnamrata.bhatia@clarchy.com

              Explainable
              Every component quotes the sentence of your brief that asked for it, and everything Clarchy assumed is listed for you to confirm.
              Priced from the source
              AWS prices come from the AWS Price List API and are refreshed every week. Azure, Google Cloud and third-party prices are marked approximate.
              Cloud-neutral
              One design, drawn on AWS, Azure, Google Cloud and open source, each in its own look.
              Ready for review
              Security, access, audit, retention and AI regulations are part of the drawing, not an afterthought.
              Private by default
              Plans run in your browser. Your documents leave it only if you choose a hosted model.
